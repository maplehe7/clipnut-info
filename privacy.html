Privacy policy

YouTube data

Clipnut Studio uses YouTube API Services with the channel owner’s permission. It reads the connected channel’s ID and name, video IDs and titles, publication dates, visibility, and video view, like, and comment counts. The dashboard displays this information to the channel owner.

When the owner requests an upload or enables automatic publishing, the clipper sends the selected video and its title, description, and visibility settings to YouTube.

Storage and access

The clipper stores YouTube authorization credentials as encrypted GitHub Actions secrets and stores upload records and statistics in a private GitHub repository. The owner’s dashboard retrieves those records from GitHub. The dashboard uses a secure session cookie for the GitHub connection.

Your choices

You can pause automatic publishing in Clipnut Studio and revoke the app’s YouTube access under Google Account connections. For privacy questions or a request to delete stored dashboard data, contact the developer using the support address shown on the Google consent screen. Manage published videos in YouTube Studio.

Google’s processing of your data is described in the Google Privacy Policy.
